# Network Topology with Router and DNS Server

## Overview
This project demonstrates a network topology designed in Cisco Packet Tracer. It consists of multiple IP networks connected through a router, with manually configured IP addresses, default gateways, and a DNS server.

## Network Features
- Multiple separate IP networks (different Network IDs)
- Router configured to connect the networks
- Static IP addressing for network devices
- Default gateway configuration for end devices
- DNS server setup for name resolution
- Communication between devices across different networks

## Objectives
- Understand how routers connect different IP networks
- Practice IP addressing and default gateway configuration
- Learn the role of DNS in a network
- Explore communication between separate subnets

## Tools Used
- Cisco Packet Tracer

## Project Files
- Packet Tracer project file (`.pkt`)
- Network topology diagram

## Learning Outcomes
This project helped me practice network topology design, IP addressing, routing between separate networks, and DNS configuration.
